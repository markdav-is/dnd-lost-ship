# Key Card System

Color-coded glass cards govern every door and robot interaction aboard the ship. Higher-rank cards open lower-rank doors. **Showing the wrong card to a reader triggers an alarm and the card is confiscated.**

## The hierarchy (original S3 scheme)

| Color | Rank / User | Opens |
| :--- | :--- | :--- |
| **Gray** | Ship Commander | Everything (and cancels full alerts) |
| **Red** | Police / Security officials | All except gray |
| **Yellow** | Medical officers | Medical chain (not orange) |
| **Orange** | Security personnel | Orange, violet, brown, jet |
| **Violet** | Technicians | Violet, brown, jet |
| **Brown** | Crew / maintenance | Brown, jet ('tween-deck tube doors) |
| **Jet black** | Passengers / colonists | Lowest |

**Campaign-added colors:** **Green** (garden level and lower-deck doors — found in crew room S50 and robot control S64), **Blue** (demanded by lower-deck police patrols), **Platinum** (the ship commander's bones, lower deck — treat as gray-equivalent or better), and the **Red card** the party carries is described as "command level" in play.

## Robot interactions

- Police robots read brown/violet/gray as friendly (heavy variant) or demand red/gray/orange (HQ garrison; failure = imprisonment behind force fields).
- Worker robots summon police if interfered with and no brown/violet/gray is shown.
- Generic androids have **built-in** yellow + violet access.

## Cards the party holds

**Red** (from the theater workstation), **green** (garden crew room), **gray** (George's), plus whatever Level 1 looting yielded — check the session notes. The commander's quarters on Level 1 hold a full set including a hidden second gray.

## DM tips

- Cards are the ship's real map: gate progress by color and let players *feel* the promotion each new card represents.
- Alarms are the tax on impatience — every misused card or console is a rolled encounter.

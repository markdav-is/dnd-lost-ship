## Building new modules

When prepping the next arc, create the module page under `/Adventures`, then add each planned encounter as a subpage using the established template: **image → read-aloud → mechanics → "Running it" → Deeper knowledge footer** (lore links only — keep the page playable at a glance). The earlier modules (1–5) predate this structure; retrofit them the same way if they'll be re-run.

## Reusable structure notes

The homebrew arc follows a reliable rhythm: **roleplay hub → overland peril → siege/set-piece → dungeon → council**. When building the next arc (the return expedition? Nordkrist's Hold? Aerun?), the same beats are proven at this table.
